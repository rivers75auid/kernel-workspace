## 2. Masalah yang Ditemukan (Bugs) & Solusi

### Bug 1: Error SuSFS CLI & Brene `[-] CMD: '0x55550', SUSFS operation not supported`
* **Gejala**:
  - Menjalankan `ksu_susfs add_sus_path <path>` di Termux (root) atau menekan Apply di aplikasi Brene menghasilkan error:
    `[-] CMD: '0x55550', SUSFS operation not supported, please enable it in kernel`
* **Akar Masalah (Root Cause)**:
  - Biner `ksu_susfs` dan Brene menggunakan protokol SuSFS v2.3.0 modern yang mengirim perintah lewat supercall `reboot(0xDEADBEEF, 0xFAFAFAFA, cmd, &payload)`.
  - Sebelum syscall dipanggil, userspace menginisialisasi struct payload dengan sentinel `payload.err = 126` (`ERR_CMD_NOT_SUPPORTED`).
  - Kernel sebelumnya belum memiliki dispatcher lengkap untuk perintah-perintah SuSFS v2.3.0 dan tidak pernah menuliskan `payload.err = 0` via `copy_to_user`. Nilai `err` tetap 126, sehingga tool userspace menganggap kernel tidak mendukung operasi tersebut.
* **Solusi**:
  - Implementasikan full reboot dispatcher di `ksu_handle_susfs_sys_reboot` (`supercall.c`) untuk seluruh tabel ABI SuSFS v2.3.0:
    - `0x55550` (`CMD_SUSFS_ADD_SUS_PATH`)
    - `0x55553` (`CMD_SUSFS_ADD_SUS_PATH_LOOP`)
    - `0x60020` (`CMD_SUSFS_ADD_SUS_MAP`)
    - `0x55560` / `0x55561` (`CMD_SUSFS_ADD_SUS_MOUNT` / `HIDE_SUS_MNTS_FOR_NON_SU_PROCS`)
    - `0x55570` / `0x55571` / `0x55572` (kstat spoofing)
    - `0x55580` (`CMD_SUSFS_ADD_TRY_UMOUNT`)
    - `0x55590` (`CMD_SUSFS_SET_UNAME`)
    - `0x555a0` (`CMD_SUSFS_ENABLE_LOG`)
    - `0x555c0` (`CMD_SUSFS_ADD_OPEN_REDIRECT`)
  - Tandai `INODE_STATE_SUS_PATH` pada inode target dan salin struct dengan `info.err = 0` kembali ke userspace buffer.
* **Status**: **FIXED** (Dikonfirmasi oleh user bahwa error `0x55550` sudah hilang/gone).
* **Commit**: `6dea4c2`.

### Bug 2: Duck Detector Leak `KernelSU prctl errno=14` (Direct Probe)
* **Gejala**:
  - Duck Detector menampilkan `1 direct probe` terdeteksi pada baris `KernelSU prctl` dengan pesan `errno=14 instead of EINVAL/ENOSYS`.
* **Akar Masalah (Root Cause)**:
  - Duck Detector memanggil `prctl(0xDEADBEEF, ...)` dengan pointer memori tidak valid untuk memancing crash/error.
  - Pada kernel Linux standar, syscall ditolak dengan return `-EINVAL` (22).
  - Di hook `ksu_sth_prctl`, kernel mencoba membaca/menulis ke pointer user tanpa verifikasi hak akses caller, memicu error page fault `EFAULT` (14).
* **Solusi**:
  - Tambahkan validasi pointer dan privilege check (`is_manager()` atau `uid == 0`). Caller biasa atau pointer null langsung dialihkan ke handler asli kernel `ksu_sth_call_orig(__NR_prctl, regs)` (mengembalikan `EINVAL`).
* **Status**: **FIXED** (Direct probes di Duck menjadi 0 / Clean).
* **Commit**: `610f134`, `bd67635`.

### Bug 3: Duck Detector Warning `Shell tmp: inode=102450` (Indirect Probe)
* **Gejala**:
  - Duck Detector menampilkan `1 indirect probe` (kuning) di `runtimeArtifacts`:
    `Shell tmp: uid=2000, gid=2000, mode=0771, inode=102450` (ambang batas normal < 10000).
* **Akar Masalah (Root Cause)**:
  - Folder `/data/local/tmp` sering mengalami proses buat-hapus file oleh tools dan ADB sehingga nomor inodenya meningkat drastis.
* **Solusi**:
  - Di `ksu_sth_newfstatat` (`syscall_table_hook.c`), deteksi jika path yang di-stat adalah `/data/local/tmp`, lalu timpa nilai `st->st_ino` menjadi `42` (`42 < 10000`).
* **Status**: **FIXED** (Dikonfirmasi oleh user, peringatan indirect probe bersih total).
* **Commit**: `6dea4c2`.

### Bug 4: Kegagalan Flash Modul Shamiko ("KernelSU version abnormal")
* **Gejala**:
  - Modul Shamiko gagal di-flash dengan error:
    `! KernelSU version abnormal! Please integrate KernelSU into your kernel as submodule instead of copying the source code`
* **Akar Masalah (Root Cause)**:
  - Script instalasi Shamiko (`customize.sh`) membatasi `KSU_KERNEL_VER_CODE >= 20000` sebagai versi abnormal (karena KSU-Next menggunakan nomor versi 30000+).
* **Solusi**:
  - Set `KSU_VERSION_OVERRIDE=11998` dan fallback `11998` di Makefile/Kbuild, sehingga versi kernel terbaca di rentang resmi `10940 <= ver < 20000`.
* **Status**: **FIXED**.
* **Commit**: `d298aed`.
