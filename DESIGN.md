# Kairos Engine — Design Direction

Owner direction (2026-11-05): "dark clean, dark soft, non emoji seperti AI slop. profesional dashboard saja clean dark dan soft."

- **What it is:** offline root-manager WebUI (KernelSU WebView) for a kernel/RAM suite on Redmi 10C. A monitoring dashboard, not a landing page.
- **Mood:** professional, dark, soft. Calm surfaces, clear data hierarchy. No emoji anywhere in UI or copy.
- **Palette (2 core + 1 accent):** deep neutral dark base (#0e1116 family), one soft muted blue accent for interactive/active states, plus muted semantic status colors (ok/warn/err) used only for real states. Nothing neon.
- **Typography:** system sans stack (offline WebView, no network fonts); system monospace ONLY for telemetry numbers and paths — numbers are the content of a dashboard.
- **Layout:** calm uniform card rhythm (a dashboard's uniformity is deliberate), one focal point per screen (the live telemetry header), whitespace as structure.
- **Dial: ENERGY 1 / RHYTHM 1 / MOTION 1** — hover/focus states only, no choreography. A monitoring tool should feel quiet.
