## 2. Masalah yang Ditemukan (Bugs) & Solusi

### Bug 1: Konflik Versi UAPI ("Manager update required" / "version too low")
* **Gejala**:
  - ReSukiSU Manager menampilkan kartu peringatan merah `Manager update required`.
  - KernelSU-Next Manager menampilkan `The current KernelSU-Next manager version is too low for KernelSU-Next to work properly`.
* **Akar Masalah (Root Cause)**:
  - KernelSU-Next legacy menggunakan UAPI v4/v5 dengan version code integer `11998` atau commit count custom.
  - ReSukiSU Manager (v4.2.0-rc3) memeriksa `kernelUAPIVersion == managerUAPIVersion` dan mengharapkan tag versi asli ReSukiSU.
* **Solusi**:
  - Hapus integrasi KernelSU-Next sepenuhnya.
  - Migrasi ke upstream resmi [ReSukiSU/ReSukiSU](https://github.com/ReSukiSU/ReSukiSU).
  - Hapus hardcode `KSU_VERSION_OVERRIDE=11998` agar ReSukiSU melaporkan versi murni yang sinkron dengan ReSukiSU Manager v4.2.0-rc3.
* **Status**: **FIXED** (ReSukiSU Manager terbaca Full Featured hijau).
* **Commit**: `1cc91c2`.

---

### Bug 2: Error SuSFS CLI / ReSuSFS `0x555b0` & `file_size too long`
* **Gejala**:
  - Memanggil `susfs set_cmdline_or_bootconfig` menghasilkan error `[-] CMD: '0x555b0', SUSFS operation not supported` atau `Error: Unsupported SuSFS command: 0x555b0`.
  - Script ReSuSFS gagal dengan pesan `file_size too long`.
* **Akar Masalah (Root Cause)**:
  - `file_size too long`: File `cmdline_or_bootconfig.txt` kemasukan komentar berulang kali akibat penggunaan `cat >>` hingga ukurannya membengkak menjadi 11 KB (batas kernel 4096 byte).
  - `0x555b0 unsupported`: ReSukiSU `ksud` menggunakan struct `SusfsSpoofCmdlineOrBootconfig` dengan buffer sebesar **8192 byte** (`err` di offset 8192), sementara tool simonpunk memakai buffer **4096 byte** (`err` di offset 4096). Kernel sebelumnya hanya menulis `err = 0` di offset 4096, sehingga ReSukiSU tetap membaca sentinel error `126`.
* **Solusi**:
  - Bersihkan `cmdline_or_bootconfig.txt` menjadi 1 baris ringkas (~1 KB).
  - Di `ksu_handle_susfs_cmd`, tulis balik `err = 0` di **kedua offset** (`*arg + 4096` dan `*arg + 8192`).
* **Status**: **FIXED**.
* **Commit**: `6d20037`, `01d29a2`.

---

### Bug 3: Linker Error vmlinux `undefined reference to susfs_*` pada ReSukiSU 4.19
* **Gejala**:
  - Kompilasi kernel gagal pada tahap `MODPOST vmlinux.o` / linking akhir:
    `undefined reference to susfs_is_current_proc_no_su`, `susfs_extra_works`, `susfs_set_current_proc_umounted`, `susfs_start_sdcard_monitor_fn`.
* **Akar Masalah (Root Cause)**:
  - ReSukiSU melacak cabang SuSFS GKI modern (`gki-android12-5.10`), sedangkan patch kernel 4.19 upstream simonpunk sudah lama tidak diperbarui dan tidak menyertakan simbol-simbol workqueue serta thread flag tersebut.
* **Solusi**:
  - Backport seluruh definisi thread flags (`TIF_PROC_UMOUNTED`, `TIF_PROC_NO_SU`, `TIF_PROC_UMOUNTED_FOR_ZYGOTE_NEXT`) ke `include/linux/susfs_def.h`.
  - Tambahkan deklarasi dan inisialisasi workqueue `susfs_extra_works` serta fungsi stub `susfs_start_sdcard_monitor_fn` di `fs/susfs.c`.
* **Status**: **FIXED**.
* **Commit**: `dd97801`.

---

### Bug 4: Compiler Error Redefinition `susfs_is_current_proc_umounted`
* **Gejala**:
  - CI build gagal saat kompilasi `fs/notify/fdinfo.c` dengan pesan:
    `error: redefinition of 'susfs_is_current_proc_umounted'`.
* **Akar Masalah (Root Cause)**:
  - Header ekstensi SuSFS di-append ke `include/linux/susfs_def.h` tanpa include guard `#ifndef`, sehingga terjadi redefinisi saat header disertakan berulang kali.
* **Solusi**:
  - Bungkus blok helper dengan `#ifndef _KSU_SUSFS_DEF_EXT_H ... #endif`.
* **Status**: **FIXED**.
* **Commit**: `a9ee7e1`.

---

### Bug 5: Error Clang Escape Sequence `\n` di Python Heredoc
* **Gejala**:
  - Kompilasi `dispatch.c` gagal dengan pesan `warning: missing terminating '"' character` dan `error: expected expression`.
* **Akar Masalah (Root Cause)**:
  - Python string tanpa modifier raw `r'''...'''` memakan karakter escape `\n`, menjadikannya baris baru harfiah di dalam sintaks kode C `scnprintf`.
* **Solusi**:
  - Gunakan raw string `r'''...'''` pada injeksi handler dispatch di `scripts/setup-ksu-susfs.sh`.
* **Status**: **FIXED**.
* **Commit**: `89a36f4`.

## 3. Tooling & Script Pendukung (`resusfs/`)

1. **`cmdline_or_bootconfig.txt`**: File teks 1 baris bersih berisi spoofing verified boot state green dan vbmeta locked (< 1.2 KB).
2. **`ReSuSFS_apply-cmdline-bootconfig.sh`**: Script apply yang menimpa file konfigurasi (anti-duplikasi).
3. **`fix_boot_hash.sh`**: Script otomatis membaca partisi fisik `/dev/block/by-name/vbmeta`, menghitung SHA-256 asli 64-karakter, dan menyuntikkannya ke `ro.boot.vbmeta.digest` untuk kelulusan Native Detector.
4. **`fix_shell_tmp_inode.sh`**: Script mounting tmpfs di `/data/local/tmp` untuk userspace reset.
5. **`fix_android_data_selinux.sh`**: Script perbaikan permission (771) dan restorecon SELinux `media_rw_data_file` untuk `/data/media/0/Android/data`.
6. **`sus_maps.txt`**: Daftar filter library injeksi Zygisk presisi (HMA-OSS, Tricky Store, Zygisk Detach, FuseHide, Zygisk Vector, ZygiskSU, ksud, su).
