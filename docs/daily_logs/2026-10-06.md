# Daily Log: 2026-10-06 (Kairos Bootloop Resolution & Android 16 Boot Success)

## Ringkasan Eksekutif
- **RESOLVED**: Kernel Kairos (`Kairos-SUSFS-Potato-fog-20261005-1630.zip`, commit `3b2ccbb`) berhasil **booting normal** di Redmi 10C (fog, bengal, SM6225) pada custom ROM baru (ROM C).
- **Akar Masalah Bootloop Sebelumnya**: ROM B yang corrupt/vendor-incompatible, bukan bug di kernel Kairos.
- **KernelSU & SuSFS**: Tetap menggunakan ReSukiSU + SuSFS v2.3.0 (percobaan migrasi ke KernelSU-Next direvert karena bug Python heredoc escape di `supercall.c`).
- **Touchscreen**: Patch Novatek NT36525B (`patch-touch.py`: ESD protect + zero-width/zero-pressure ghost touch filter) sudah ikut ter-flash.

## Kronologi & Temuan Kritis

1. **Investigasi Bootloop**:
   - ROM A: Bootloop (sempat bootanimation).
   - ROM B: Bootloop (tidak sampai bootanimation).
   - ROM C: **Booting normal ke homescreen!**
   - Bukti forensik: Embedded config `IKCFG_ST` antara build 30 Sept (ROM A) dan 5 Okt (ROM B) **100% identik (0 diff)**. Membuktikan perbedaan perilaku murni dari sisi vendor/ROM.

2. **Perbandingan dengan NeutronKernel (Works)**:
   - Neutron (`4.19.325-cip134-st18-NeutronKernel`) menggunakan hook `ksu_lsm_hook` (LSM hook GKI).
   - Neutron mengaktifkan `CONFIG_RD_LZ4=y` dan `CONFIG_USERFAULTFD=y`.
   - Di Kairos, kedua config tersebut masih ter-reset menjadi `# is not set` oleh mekanisme `conf --syncconfig` di Kconfig Linux 4.19 saat ada unresolved symbols (`CONFIG_EMBEDDED=y` reset cascade).

3. **Percobaan Migrasi KernelSU-Next (Direvert)**:
   - Commit `afa2c88` mencoba kembali ke KernelSU-Next legacy (`CONFIG_KSU_SYSCALL_TABLE_HOOK=y`).
   - Build gagal di GitHub Actions karena string literal di `supercall.c:191` terpotong akibat Python multiline escaping.
   - Commit `2f9b54a` me-revert perubahan, mengembalikan codebase ke ReSukiSU stable profile.
