## 2. Masalah yang Ditemukan (Bugs)

### Bug 1: Duplikasi Objek di `scripts/dtc/Makefile`
* **Gejala**: Kompilasi kernel gagal saat me-link Device Tree Compiler (`dtc`). Muncul error simbol duplikat pada `yamltree.o`.
* **Penyebab**: Makefile bawaan tree memanggil build YAML parser yang tidak kompatibel dengan environment CI ubuntu-22.04.
* **Solusi**: Dibuat patch bersih `patches/dtc_Makefile` tanpa dependensi YAML (`NO_YAML`).

### Bug 2: Missing Link Symbols KernelSU-Next <-> SuSFS
* **Gejala**: Linker kernel gagal menemukan fungsi yang dibutuhkan SuSFS dan `fs/namespace.c`.
* **Penyebab**: KernelSU-Next cabang `legacy` tidak memiliki glue code bawaan untuk SuSFS simonpunk.
* **Solusi**: Ditambahkan compatibility glue code di `fs/susfs.c`:
  - `susfs_is_current_ksu_domain()`
  - `susfs_is_current_zygote_domain()`
  - `ksu_try_umount()`
  - `susfs_try_umount_all()`
