## 2. Masalah yang Ditemukan (Bugs) & Solusi

### Bug 1: Aplikasi Bank Force Close (Deteksi Root Telanjang)
* **Gejala**: Aplikasi perbankan langsung force close saat diluncurkan.
* **Akar Masalah #1 (Zygote Credential Timing)**:
  - Di Android 14/15/16, Zygote mengubah SELinux domain proses anak menjadi `u:r:untrusted_app:s0` *sebelum* memanggil syscall `setresuid`.
  - Fungsi `is_zygote(current_cred())` hanya mengecek kredensial proses saat itu, sehingga selalu mengembalikan `false`.
  - Blok unmount `susfs_try_umount_all` dilewati sepenuhnya. Aplikasi bank tetap melihat mountpoint root dan modul.
* **Akar Masalah #2 (Filter SuSFS Tidak Pernah Aktif)**:
  - Seluruh hook SuSFS di VFS (`/proc/self/mountinfo`, `dcache` path lookup, `generic_fillattr`) dipagari oleh bitmask:
    ```c
    current->susfs_task_state & TASK_STRUCT_NON_ROOT_USER_APP_PROC
    ```
  - Flag ini tidak pernah diset di `setuid_hook.c`, sehingga semua fitur isolasi SuSFS tertidur (dormant).
* **Solusi**:
  - Dibuat fungsi `is_child_of_zygote()` yang memeriksa `current_cred()` dan `current->real_parent->cred`.
  - Set bit `TASK_STRUCT_NON_ROOT_USER_APP_PROC` pada `current->susfs_task_state` untuk `is_appuid` dan `is_isolated_process`.
* **Commit**: `baea87f` (PR #5).

### Bug 2: Konflik Modul BRENE (13 Fitur vs 9 Fitur)
* **Gejala**: Aplikasi bank berjalan saat BRENE dimatikan, tetapi langsung crash jika BRENE aktif. Modul BRENE melaporkan 13 fitur aktif di kernel ini (di kernel stabil hanya 9).
* **Akar Masalah**:
  1. `CONFIG_KSU_SUSFS_SUS_OVERLAYFS=y`: Memodifikasi penanganan `ovl_path_lowerdata` di `fs/overlayfs/inode.c`. Saat BRENE meng-overlay path sistem, dereference pointer memicu rekursi status `ST_RDONLY & ST_RELATIME`, menyebabkan **SIGSEGV / crash JVM** di runtime Android.
  2. `CONFIG_KSU_SUSFS_AUTO_ADD_TRY_UMOUNT_FOR_BIND_MOUNT=y`: Menambahkan bind mount FUSE storage milik BRENE ke daftar unmount otomatis secara agresif, membuat file descriptor bank stale (`EBADF`).
* **Solusi**:
  - Matikan `SUS_OVERLAYFS`, `AUTO_ADD_TRY_UMOUNT`, dan `AUTO_ADD_SUS_*` di `configs/ksu_susfs.config`.
* **Commit**: `2051ebb`.

### Bug 3: Fitur `sus_map` Tidak Ada di Kernel 4.19
* **Gejala**: Modul BRENE melaporkan 8/9 fitur aktif. File `.so` injeksi Zygisk/BRENE tetap terbaca oleh library anti-tamper bank via `/proc/self/maps`.
* **Akar Masalah**:
  - Di upstream resmi simonpunk (`susfs4ksu`), fitur `sus_map` hanya diimplementasikan untuk kernel GKI (5.10+). Cabang `kernel-4.19` tidak pernah mendapatkan fitur ini.
* **Solusi**:
  - Mem-backport penuh `CONFIG_KSU_SUSFS_SUS_MAP` ke Kernel 4.19:
    1. Definisikan `CMD_SUSFS_ADD_SUS_MAP (0x60020)` dan `AS_FLAGS_SUS_MAP (39)` di `include/linux/susfs_def.h`.
    2. Hook fungsi `show_map_vma` dan `show_smap` di `fs/proc/task_mmu.c` agar langsung `return 0` jika file memori ditandai `SUSFS_IS_INODE_SUS_MAP`.
    3. Tambahkan handler `susfs_add_sus_map` di `fs/susfs.c` dan routing reboot di `supercall.c`.
* **Commit**: `f6c14b6`.

### Bug 4: Compiler Error Implicit Declaration `susfs_try_umount`
* **Gejala**: Build CI gagal dengan error: `error: implicit declaration of function 'susfs_try_umount' [-Werror]`.
* **Penyebab**: Fungsi `susfs_try_umount(uid)` dipanggil tanpa dibungkus `#ifdef CONFIG_KSU_SUSFS_TRY_UMOUNT`.
* **Solusi**: Tambahkan proteksi ifdef di fungsi `susfs_try_umount_all` di `scripts/setup-ksu-susfs.sh`.
* **Commit**: `541a5f2`.
